Production Deployment Recipes

Run PocketFleet seamlessly in the background on Linux VPS, Windows workstations, or Docker containers.

/etc/systemd/system/pocketfleet.service 
[Unit]
Description=PocketFleet Telegram Coding Daemon
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/home/ubuntu/projects/my-repo
Environment="POCKETFLEET_BOT_TOKEN=your_telegram_bot_token"
ExecStart=/home/ubuntu/.local/bin/pocketfleet --cwd /home/ubuntu/projects/my-repo
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
sudo systemctl daemon-reload && sudo systemctl enable --now pocketfleet
docker run (Isolated Sandbox) 
docker run -d \
  --name pocketfleet \
  --restart unless-stopped \
  -v /home/user/my-repo:/workspace \
  -e POCKETFLEET_BOT_TOKEN="your_bot_token" \
  -e ANTHROPIC_API_KEY="your_anthropic_api_key" \
  python:3.11-slim \
  sh -c "pip install pocketfleet && pocketfleet --cwd /workspace"
run_pocketfleet.bat (Windows Startup) 
@echo off
cd /d "D:\projects\my-app"
pocketfleet

💡 Press Win+R, type shell:startup, and place a shortcut to this .bat file.

nohup background session (No Root Needed) 
nohup pocketfleet --cwd /var/www/my-project > pocketfleet.log 2>&1 &
tail -f pocketfleet.log
